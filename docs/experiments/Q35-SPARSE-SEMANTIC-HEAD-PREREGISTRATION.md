# Q3.5 preregistration — sparse random-feature semantic head

Status: **preregistration candidate, not authorized to run.** This freezes the
science and the gates. Before any execution, the executable contract, harness,
mechanics hashes, and authorization file must be frozen in
`atimics/zero-grounded-literary-lm` and merged. No training is authorized by
this document.

Supersedes the mis-numbered `Q27-FLAGSHIP-PROPOSAL.md` flagship for the semantic
path. Q2.7 and the Q2.7.x identifiers are already taken by settled upstream
records (`Q27-FLAGSHIP-PROPOSAL.md`, Revision 2).

## 1. Why this experiment exists

Q3.4 trained the same frozen-base 7,685-parameter **linear** head on 4,500
canonical plus 4,500 semantic records and reached only 208/500 (41.6%) on the
semantic private set. Its recorded next boundary is, verbatim:

> "Build the immutable corpus pipeline, then compare adequate exposure and a
> small nonlinear probe before training a larger routed expert."

Q3.5 is the **small nonlinear probe**. It tests whether the semantic gap is a
*feature-map* limitation rather than a data or representation limitation.

The fly-brain argument: a fixed, unlearned sparse expansion followed by
winner-take-all produces a high-dimensional code in which a small linear
readout can separate inputs that are not linearly separable in the base
features. This is the mushroom body architecture (projection neurons → sparse
Kenyon cells → small MBON readout), and it is also a random-features network.
It changes only the representation between the frozen features and the trained
head.

## 2. Frozen question

Does replacing the linear 1536-to-5 head input with a fixed sparse ternary
random expansion followed by winner-take-all, leaving the base, the data, the
optimizer, the seed, the update budget, and every gate unchanged, lift the
semantic-private feature accuracy above the Q3.4 no-go gate of 80% overall and
60% per class while preserving canonical routing?

### Arms

Two arms run in the same execution, over identical features, projection, head
size, optimizer, batch order, seed, and update budget. The only difference is
winner-take-all.

- **Arm S (sparse, primary claim):** ReLU(P·x) then top-k WTA.
- **Arm D (dense control):** ReLU(P·x) with no WTA.

Arm D isolates sparsity from added dimensionality and nonlinearity. The
historical Q3.4 linear result (1,536-to-5, 41.6%) is the external reference; it
is not re-run and cannot change this contract.

## 4. Gates

Identical to Q3.4. No threshold is relaxed.

Semantic package gates, on the packaged runtime:

- semantic private and untouched semantic confirmation: ≥ 80% overall, ≥ 60%
  per operation, ≥ 75% lexical, ≥ 65% implicit;
- canonical private and combined disjoint public-plus-promotion: ≥ 99%
  operation overall, ≥ 98% per operation; closure, syntax, arguments, and
  oracle arithmetic exact;
- rejected routes make zero state mutations; non-Q probabilities are
  byte-for-byte identical.

Candidate selection uses private data only. Confirmation, public, and promotion
data can only reject a selected candidate, never change the selected update.

## 5. Decision rule

- **`go`** — one arm reaches the semantic gate on private, then passes
  confirmation and combined canonical. The passing arm is frozen as the
  candidate.
- **`no-go`** — neither arm reaches the semantic gate, or a passed arm fails
  confirmation or canonical regression.
- **`mechanics_failure`** — feature, projection, or determinism check fails
  before measurement.

A `go` establishes operation-routing transfer on the explicit/semantic
distribution. It does not establish open-domain semantic understanding,
natural-language argument binding, or end-to-end calculation.

## 6. Recorded metrics (mediators)

Beyond the gate metrics, the run records:

- mean and maximum active-set size per class (WTA should make this constant at
  307 for Arm S);
- pairwise active-set overlap between the five operation classes, semantic
  private split (the fly-mechanism mediator);
- per-class recall and the full 5×5 confusion matrix for both arms;
- training records consumed (Q3.4 consumed 6,400 of 9,000, less than one
  epoch — this experiment keeps that fixed so it is not a confound).

## 7. Falsification map

| Outcome | What it closes | Next boundary |
| --- | --- | --- |
| Arm S passes, Arm D fails | Sparse WTA coding is the active ingredient; sparse random features unlock a linearly inseparable semantic readout | Replicate the mechanism on a second task family; test in the ZERO.5 C line |
| Both arms pass | The win is added dimension/nonlinearity, not sparsity | Retire the sparsity claim; simplify to a dense random-feature probe |
| Both arms fail as Q3.4 did | Nonlinear random features do not fix the semantic gap; the deficiency is data/exposure or the frozen representation itself | Run the adequate-exposure ablation (Q3.6) before any representation change |
| Canonical regression | The feature map destroys canonical routing | Reject; test a canonical-anchored feature map |
| Determinism failure | Implementation invalid | No scientific inference; repair and re-register |

## 8. Stop boundary

One seed, one execution, two arms, local compute only, maximum spend $0.15.
No language gate, deployment, extra seed, resume, hyperparameter search, or base
fine-tuning. This document authorizes nothing by itself.
