Ownership

One lab, three clear boundaries.

Braid · data plane

Compiles governed releases, representations, target streams, rights records, split seals, and verification evidence. A Braid release never authorizes model training.

ZERO · model engine

Owns the C11 model, training loop, frozen evaluator, execution receipt, and private checkpoint. A ZERO result never promotes itself.

ilXyr · evidence plane

Owns the cross-project registry, admission status, forecast history, evidence classification, and promotion decision. New runs require an ilXyr registration.

C5 causal chain

Content first. Learning bridge second.

C4.3 control: retrieval choice reached 53.76%; claim and retention gates passed, but retrieval and cloze kept the experiment at no-go.

C5.1 StateBridge text: the base remained 4,852,992 parameters. Exactly 25% of the matched stream became Braid structured-state text. Retrieval choice fell to 52.57%, pair-exact to 50.94%, and claim choice to 56.14%. Structured content alone was not enough.

C5.2 TargetBridge auxiliary: the C5.1 stream stays frozen. The only treatment is a factorized verified state-target head at loss weight 0.1. The run must improve both state factors and the frozen retrieval audit while preserving claim and language retention.

Director policy

How the registry stays current.

  • An already-started authorized run may finish. It is then imported with its real chronology.
  • A new run requires an ilXyr registration before execution.
  • External completed runs are never relabelled as forecast-risked ilXyr experiments.
  • Plane-prefixed display names distinguish Braid Corpus 5.2 from ZERO5 C5.2.
  • A C5.2 pass authorizes a frozen multi-seed request, not promotion or sealed-test access.
